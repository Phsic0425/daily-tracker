# 日常记账 v8

个人记账 + 待办管理 + 日程规划 + 课表 + 资产管理 PWA，手机/平板/电脑通用，数据云端同步。

## 功能

| 模块 | 功能 |
|------|------|
| 💰 记账 | 收支记录、分类统计、快捷模板、拍照记账、月度/年度报表、资产账户联动 |
| 💳 资产 | 多账户管理（银行卡/微信/校园卡等）、总资产显示、资产变动追踪、转账/对账 |
| ✅ 待办 | 优先级+截止日期、无限层级子任务、折叠展开、临期/超时提醒 |
| 📅 日程 | 月历/周视图、7 种重复规则（含农历）、倒计时、浏览器通知 |
| 📋 课表 | 每周课程表、单双周/学期周次、课程与日程联动 |
| ☁️ 同步 | GitHub Gist 云同步、按记录合并、历史版本回滚、本地快照、连接码多设备配对 |

## 使用

直接用浏览器打开 `index.html`，或部署到静态服务器。

应用内点 `⋯` → `📖 使用说明` 查看完整文档。

## 技术

- 纯原生 JS，无框架，无构建工具
- localStorage 本地存储 + GitHub Gist 云同步（按记录级别合并）
- PWA 可安装到桌面/主屏幕，Service Worker 自动更新
- 农历支持：lunar-javascript (CDN)
- 响应式：手机 480px / 平板 600px / 电脑 800px
